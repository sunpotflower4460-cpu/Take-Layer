# Phase 1.5 — Short Foundation

## Purpose

Phase 1.5 proves the deterministic one-video short-form editing substrate before AI Director or multi-part editing is allowed to depend on it.

The product boundary is intentionally simple:

> synchronized TakeLayer Project → inspectable ShortEditDraft → deterministic 9:16 renderer

AI is not required in this phase.

## EditingPlan precursor

`ShortEditDraft` is the first concrete editing-plan representation. It contains only inspectable parameters:

- Project Timeline range start/end.
- deterministic 9:16 crop/zoom/pan (`zoom`, `focusX`, `focusY`).
- title text.
- user-supplied timed lyric cues.

Future AI Director work may propose these values, but it must not bypass them and directly mutate renderer internals.

## Synchronization invariant

Short export must never recreate synchronization math.

Every short range is expressed on the Project Timeline and converted through `TimelineMapper.makeMapping(project:projectTimelineStartSec:durationSec:)`.

This preserves:

- `songStartRawSec`.
- `songStartAudioSec`.
- `offsetMs` semantics.
- pre-roll behavior.
- completed-WAV authority.

## Rendering contract

Phase 1.5 output is:

- 1080 × 1920.
- 30 fps.
- one source video.
- completed WAV as program audio.
- camera audio excluded.
- aspect-fill crop into 9:16.
- zoom range 1×–3×.
- normalized focus X/Y range 0–1.
- deterministic title layer.
- deterministic user-supplied lyric layer.

Raw media remains non-destructive.

## Preview contract

The user can:

1. choose a short range on the Project Timeline.
2. seek the source preview within that range.
3. adjust crop/zoom/pan.
4. edit the title.
5. add lyric cues with explicit Project Timeline start/end times.
6. micro-adjust the plan.
7. export the same saved plan.

The preview is an editing monitor; the export renderer remains the source of truth for the final pixels.

## Lyrics policy

Phase 1.5 does not generate lyrics.

Only user-supplied text is rendered. Future lyric alignment may assist timing, but generated text must not silently replace formal/user-confirmed lyrics.

## Tests / merge gate

Before merge:

- existing TimelineMapper tests remain green.
- Project Timeline short-window mapping is tested.
- out-of-range short windows are rejected.
- portrait crop geometry is tested.
- landscape → 9:16 aspect-fill geometry is tested.
- crop normalization is tested.
- XcodeGen build and iOS Simulator XCTest are green.

## Explicitly out of scope

- automatic highlight selection.
- performer detection.
- automatic face/body tracking.
- generative titles.
- generative lyrics.
- automatic lyric alignment.
- style presets generated by AI.
- preference learning.
- multi-part camera switching.

Those capabilities belong to later Director phases and must control the deterministic primitives introduced here rather than replacing them.
